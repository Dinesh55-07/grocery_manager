# Grocery List Manager

Frontend-first CRUD demo for a grocery list application.

## Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome

## Current Scope
- Dashboard UI
- Add item form
- Edit item form
- About page
- Flask API connected to local MySQL CRUD

## How to set up the database
1. Open MySQL Workbench.
2. Run `database/grocery_manager.sql` to create the database and table.
3. Optionally run `database/sample_data.sql` to load sample grocery items.

## How to run the app
1. Start the Flask server from `backend/app.py`.
2. Open `http://127.0.0.1:5000/` in your browser.
3. Use the dashboard to create, read, update, and delete items.
